Shadowed rules live

Rules that can never match or never act: hidden below a broader rule, below a catch-all, duplicated, superseded by a stricter rule, disabled, or naming objects that no longer exist. Read live from the tenant, only what is in scope on the Scope page, with the rule that hides each one and the fix.

How it works
  1. Analyze. The page reads the rules of every policy in scope on the Scope page (Inline Web, Endpoint, Email and SaaS DLP, URL filtering, Cloud App Control, SSL inspection and, with ZIA platform ticked, Cloud Firewall), shown live as it reads. Stop ends the read at once.
  2. Read the findings, grouped by policy and sorted high first: each names the rule, the rule that hides it, why in one sentence, and what to do.
  3. Export the findings as CSV or JSON for the customer's change request.
A rule is reported only when every criterion both rules carry can be compared; anything this page cannot compare safely counts as "not shadowed", so it never invents a finding. Inline Web DLP is first match By Rule Order unless the tenant runs Evaluate All Rules; when the mode cannot be read, rule order is assumed and every finding says so. Endpoint and Email DLP evaluate every rule and the most restrictive wins, so their rules can be superseded, never shadowed. Nothing is written to the tenant.
