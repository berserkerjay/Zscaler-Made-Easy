How much of your web traffic Zscaler does not inspect, why, and what to change to fix it. Run it, then work through the recovery plan from step 1. Read-only: nothing is changed in the tenant.

How it works
  1. Check coverage. It reads the SSL inspection rules and, when ZCC is in scope on the Scope page, the Client Connector profiles and PAC files. With ZIA Insights in scope it also asks how much HTTPS and HTTP traffic was inspected.
  2. Read the causes. Each thing that leaves traffic uninspected is listed with the rule or setting behind it and how risky it is. Leaving file sharing or AI tools encrypted is high risk; leaving banking or health sites encrypted for privacy is expected.
  3. Follow the recovery plan. The changes are ordered biggest risk first, each with where to change it and whether it is safe. Run it again afterwards to see the trend.
