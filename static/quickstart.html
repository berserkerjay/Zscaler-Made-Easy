Quick Start Assessment

Four steps from an empty form to a scored maturity report. Everything is read-only: the tool only reads the tenant.

← Back to the assessment
STEP 1

Get API credentials

Create an OAuth API client in ZIdentity with read-only access to the services you want to assess.

STEP 2

Enter tenant details

On the assessment page, open Connect to the tenant → Tenant details, fill in the organisation, cloud, vanity domain, client ID and secret, and click Authenticate.

STEP 3

Choose a scope

Keep the DLP scope for a data protection engagement, or tick ZIA, ZPA, ZCC, GenAI, Automation and Compliance for the full platform.

STEP 4

Run and download

Run the assessment (about 90 seconds), read the findings, and download the scored maturity report as Word or JSON.

Getting Zscaler OneAPI credentials

  1. Log into ZIdentity for the customer (https://<vanity>.zslogin.net) or the Zscaler admin portal.
  2. Go to Integration → API Clients (older tenants: Administration → API Key Management → OneAPI Credentials).
  3. Click Add API Client and name it, for example DLP Assessment.
  4. Grant read-only scopes for the services in scope: zia:read, zcc:read, zpa:read. Deploying policy packs later needs a ZIA role that can write DLP dictionaries, engines and policy.
  5. Copy the Client ID and the Client Secret (shown once) into the tenant details.
  6. The Vanity Domain is the short name before .zslogin.net: for https://acme.zslogin.net enter acme.

Finding the ZPA Customer ID (only for ZPA checks)

  1. Log into the ZPA admin portal.
  2. The URL contains the customer ID: https://admin.private.zscaler.com/app/<CUSTOMER_ID>/dashboard.

Security note

  • The assessment makes read-only API calls; nothing in the tenant is modified.
  • Credentials stay on this machine; they are never sent to any external service.
  • Rotate the client secret periodically, per Zscaler best practice.
