SOC review

Two checks a security operations team runs on the tenant. Admin access shows who can change ZIA, ZPA, Client Connector, ZDX and ZIdentity: the admins and roles, who has full and who has limited rights, admins that are off or unused, and the API keys and clients. Logging shows what is sent to your SIEM and what is not. Pick one, then fix what says Fix first. Nothing is changed in your Zscaler.

How it works
  1. Tick what to read on the Scope page. Admin access needs RBAC (and ZPA, Client Connector or ZIdentity for theirs). Logging needs ZIA platform, ZPA, Client Connector or ZDX. Nothing else is read.
  2. Click Read admin access or Read logging. The page reads once, shown live. Stop ends the read at once.
  3. Fix the findings, Fix first, then Review. Unknown means the API does not say, so it is not counted as fine.
Never read into this page: passwords, key and token values, client secrets, or a log feed's headers. A log destination shows its host name only.
