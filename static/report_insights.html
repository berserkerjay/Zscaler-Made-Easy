What this does and does not cover. Aggregated numbers from ZIA Insights (the Z-Insights API): web traffic by action and by location, cloud applications (Shadow IT), SaaS security (CASB) by application, firewall traffic by action, and the users with the most security incidents. Insights cannot break traffic down by URL category, by user, by policy rule or by one host, so this page does not show those, and never guesses them. User names are shown on this screen only: they are not logged, kept or exported. Nothing is written to the tenant.
How it works
  1. Pick a time window (up to 92 days, within the last 180) and the unit for web traffic: transactions or bytes.
  2. Read Insights. About nine questions go to ZIA Insights, one at a time, shown live; Stop ends the read at once with nothing more asked.
  3. Sort and export. Click a column heading to sort. CSV and JSON exports carry every table except the per-user one.
