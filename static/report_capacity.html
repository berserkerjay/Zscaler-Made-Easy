How it works

Tick Cloud & Branch Connector, ZPA or ZIA platform on the Scope page, then run the review. Used counts are read now (GET only). Licensed seat counts come from the tenant's subscription list when it states them, otherwise from the file capacity_entitlements.json you keep beside the app. A metric that cannot be read says so; it is never guessed.
