Audit timeline

Who changed what in the tenant, and what Zscaler Made Easy did, on one timeline. ZIA's admin audit log for the window you choose is merged with Zscaler Made Easy's own deployment records and audit log, newest first. A change someone else made to an object Zscaler Made Easy created is marked, and a change with before and after values shows what changed field by field.

How it works
  1. Choose a window (the last 7 days by default; ZIA keeps its audit log for up to 180 days) and whether to include ZIA's admin audit log.
  2. Build the timeline. Zscaler Made Easy asks ZIA to prepare an audit log report for the window, waits for it and downloads it as CSV, then adds its own deployment records and audit log.
  3. Filter and read. Filter by source, admin, action, object or any text. A row marked changed by someone else is a change to an object Zscaler Made Easy created that no Zscaler Made Easy write explains; open a row for the field-by-field change and the raw audit log entry.

Reading ZIA's audit log needs Automation readiness in scope on the Scope page (its API permissions include the audit log) and an API role that may view the audit log. Asking ZIA for the report is a POST, but it changes no configuration: it only prepares a file to download, so this page needs no write mode and writes nothing to the tenant. Without the ZIA part, only Zscaler Made Easy's own records are shown, for every tenant.
