How it works
  1. Tick what to read on the Scope page. ZIA platform reads the isolation profiles, Browser Control and the URL filtering and Cloud App Control rules that isolate. ZPA reads the isolation controls, Browser Access, managed browsers, browser protection, Privileged Remote Access and user portals (it needs a OneAPI API client and the ZPA customer ID). Nothing else is read.
  2. Read. The page reads once, shown live as it reads. Stop ends the read at once.
  3. Fix the findings, high first: each says what is wrong in plain words, why it matters for data protection and what to change. Export them as Excel or JSON for the change request.
