Bulk changes

Enable or disable many rules at once, put a policy's rules in a new order, move URLs between custom URL categories, move ZPA domains between application segments, change settings on many ZPA segments at once, and create, edit, copy or delete one rule (Build new, Edit a rule). Every change is previewed item by item from the tenant as it is now, applied only in write mode after you confirm the exact plan, checked again right before each write, read back, recorded and reversible with Undo.
