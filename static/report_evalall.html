Evaluate All Rules and the tie-breaker

How ZIA decides which DLP rule applies when every rule is evaluated, and what happens when two matching rules carry the same action. Inline Web DLP (with the switch on), Endpoint DLP and Outbound Email DLP evaluate all rules; SaaS Security API DLP rules are the one exception: rule order, first match wins, per rule type.
