AI Guard

What Zscaler AI Guard checks in the prompts people send to GenAI apps and the answers they get: its detection policies, the rules that pick a policy, the LLM applications and their credentials (names only, never a key). Test a prompt sends one made-up prompt from a fixed list and shows what each detector did. Nothing is changed in your Zscaler.

How it works
  1. Tick AI Guard on the Scope page. AI Guard is reached only with a OneAPI (ZIdentity) API client. Nothing else is read.
  2. Read. The policies, rules, applications and credential names are read once. The assessment scores the same configuration (checks AIG.1 to AIG.6).
  3. Test a prompt to see the policy at work. Only the made-up prompts listed are ever sent; on a live tenant it needs the server's AI Guard API key.
