How do I get API credentials? ›

Getting Zscaler OneAPI Credentials

  1. Log into your Zscaler admin portal (admin.<your-cloud>.net)
  2. Go to Administration → API Key Management → OneAPI Credentials
  3. Click Add API Client and give it a name like DLP Assessment
  4. Grant these read-only scopes: zia:read, zcc:read, zpa:read (or minimum needed for your scope)
  5. Copy the Client ID and Client Secret into the form below
  6. Note your Vanity Domain (e.g., acme) — it's shown in the OneAPI setup page

Finding your ZPA Customer ID (optional, for ZPA checks)

  1. Log into the ZPA admin portal
  2. Look at the URL — it contains your customer ID: https://admin.private.zscaler.com/app/<CUSTOMER_ID>/dashboard

Security note

  • This tool makes read-only API calls — nothing is modified
  • Credentials stay on your machine — they are not transmitted to any external service
  • Rotate your client secret periodically per Zscaler best practices

Inline DLP Rule Migration — Evaluate All Rules

Scope: Inline Web DLP rules only (/zia/webDlpRules). Follow the steps below in order. Step 3b is destructive and optional. All write actions default to dry-run for safety.

STEP 1

Assess Current Status

Check whether the tenant is in Rule Order or Evaluate All Rules mode.

STEP 2

Download Current Rules

Pull the live inline DLP rule set from Zscaler and save a backup before any changes.

STEP 3

Optimize for Evaluate All Rules (with Exceptions)

Generate the new rule ordering. Optionally declare exceptions before optimizing.

Exceptions (optional)

💡 Skip auto-optimization by uploading a JSON of pre-curated rules in the order you want them posted (Step 5 will use that order directly).

STEP 3B · OPTIONAL · DESTRUCTIVE

Delete All Existing DLP Rules

Use this only when migrating to Evaluate All Rules with a fresh re-post. Wipes every Inline Web DLP rule so Step 5 can re-create them in the optimized order without conflicts. Cannot be undone via API — make sure Step 2 backup is saved first.

STEP 4

Enable Evaluate All Rules

Three-stage flow: 1. Check current state · 2. Enable (dry-run → plan) · 3. Activate the change. If the API exposes the toggle, Activate flips it for you. Otherwise you'll be handed off to the admin portal and can click "Mark Activated" once done.

STEP 5

Post New Rules

Apply the optimized ordering. Choose mode based on whether you ran Step 3b.
