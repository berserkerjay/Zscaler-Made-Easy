Device posture

Shows which device checks (posture profiles and trusted networks) your ZPA access rules ask for, which rules let devices in without a real check, and every access rule's conditions in plain words. Read ZPA, then fix the rules under Findings first, high before medium.

How it works
  1. Tick ZPA on the Scope page and give the ZPA customer ID with the API client (Connect to the tenant). Nothing is read otherwise. Tick Client Connector too to also read its trusted networks.
  2. Read device posture. ZPA is read once, list by list, and shown live; Stop ends the read at once and keeps nothing.
  3. Read the findings, then the posture profiles (what kind of check each is, and which rules use it) and the access rules in plain words. Export everything to Excel.
Read-only: nothing is written to the tenant. A list that could not be read is said so, never shown as empty.
