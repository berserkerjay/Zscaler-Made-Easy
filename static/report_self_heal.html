Self-healing

This page shows what Zscaler Made Easy fixed by itself, and the settings in your Zscaler that changed since you approved them. Nothing in your Zscaler changes until you click Heal.

This app

The app looks after itself: a job that got stuck, a saved file that was damaged, a file others could read, a lock left behind, a pause that lasted too long. When it can fix the problem it does, and says what it did. When it cannot, it tells you the next step. It never changes your Zscaler.

    Your tenant

    When a setting you approved changes back (a rule turned off, an action made weaker, an engine or dictionary edited or deleted, a fix someone undid), it shows up here with the exact change that puts it back. Heal makes that change the safe way: write mode must be on, the setting is read again first and nothing happens if it moved again, you type a confirmation, the app checks that the change took, and you can undo it. Changes made through this app are never shown as drift.
