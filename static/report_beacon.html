Tenant API watch (optional, read-only)

Reads from one tenant only the endpoints that belong to what is in scope on the Scope page: the scopes ticked there. For every scope, only the channels marked Zscaler are read, exactly as the assessment reads them: an alternative or unticked channel is not, so GenAI & prompts reads nothing without GenAI Security on Zscaler, and ZIA platform's Cloud Apps checks need Cloud App Control. Every request counts against the tenant's ZIA API rate limit, so nothing else is read — GET only, about one request a second — and it records what each answered (OK, 403, 404, 429, timeout, error) and how many items. When this page cannot see the Scope page's ticks it uses the selected profile's saved scope; with every scope unticked, or nothing saved, it does not run. The next watch of the same tenant says which endpoints now answer differently (only the endpoints both watches read; a changed scope is said): a 200 that became 404 is an endpoint that moved; a 200 that became 403 is a permission that was taken away. The timer never runs this; only you do, here.
