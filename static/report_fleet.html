The enrolled devices and the profiles that govern them, together: which services really run, which devices Zscaler cannot see, how far behind the client is, which app profile is weakest, and what to fix first, ranked by the devices it affects. Read-only, and only when ZCC is in scope on the Scope page.

How it works

  1. Read the fleet. The app reads the Client Connector app and forwarding profiles and the hosted PAC files (the same paced reader the Path analyzer uses), then the enrolled devices and their per-device service status (ZIA, ZPA, ZDX). It takes a minute; Stop ends it at once.
  2. Read the alerts. Blind spots, bypass risk, ghost devices, registration anomalies, multi-device users and version drift, each with its exact definition beside it.
  3. Fix in order. The remediation plan ranks every gap by its impact times the devices it affects, with the fix in plain words. Export it as CSV, or everything as one Excel workbook; tick counts only to leave every user and device name out.

Device and user names are shown on this page because you need them to act; they are never written to a log. If the API client may not read devices, the page says so and shows the configuration only: never zeros as if the fleet were healthy.

DNS records for client hostnames

For ZPA client-to-client access: one DNS name per enrolled device (<hostname>.<domain>), sent to the client-to-client resolver you name. Built from the fleet read above, so read the fleet first. You get the text to download for Unbound, BIND (forward zones and a zone file) and a CSV of every name: the app sends nothing to any DNS server and applies nothing. Hostnames become valid DNS labels (letters, digits and '-'); renames, duplicates and collisions are listed.

Install command builder

Builds the Client Connector install command (MSI or EXE on Windows, the installer app on macOS) and a script to run next to the installer. Pick an app profile from the fleet read to fill in its policy token. Tokens and passwords show as ******** until you click Reveal; nothing is logged or saved.
