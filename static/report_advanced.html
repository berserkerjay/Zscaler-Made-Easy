Advanced settings

Add your own policy packs so they show up everywhere the app offers a pack: Deploy Policy Packs, the Data Flow Map, the Terraform hand-off and the detection validator. A pack is a set of dictionaries, engines and rules; you can bring one as JSON (including Zscaler's own API export), as Terraform for the Zscaler provider, or as a ZIP of either. Every pack you add is transcribed to Terraform on the spot, so the same policy exists in a vendor-neutral form you can export from the library.

Add a policy pack

Pick the files, check them, then add. Nothing touches your Zscaler tenant here: adding a pack only stores it on this machine. Deploying it is a separate, reviewed step in Deploy Policy Packs.

JSON pack, the three pack files, Terraform (.tf) or a ZIP. Up to 8 MB.

    What the app accepts

    One JSON file (easiest)

    An object with a name, a description and three lists: dictionaries, engines and policies. Each dictionary has a name, patterns and phrases; each engine has a name and an expression such as (D:My Dictionary > 2); each rule names its engines and its channel (web, endpoint, saas, email, or a containment channel).

    Download a complete example

    The three pack files

    dlp_dictionaries.json, dlp_engines.json and dlp_policies.json (plus an optional pack.json for the name and description), the same layout as the packs the app ships with. A ZIP of a pack folder works too.

    Terraform

    Files for the zscaler/zia provider: zia_dlp_dictionaries, zia_dlp_engines, the DLP rule resources (web, endpoint, SaaS, email) and the containment rules (Cloud App Control, File Type Control, URL Filtering, SSL Inspection). A workspace exported from the Terraform hand-off round-trips. Objects must be referenced by name; an id copied from another tenant is reported because it will not exist in yours.

    Every upload is checked before it is stored: patterns must compile, dictionaries must fit Zscaler's limits, engines must reference dictionaries, rules must reference engines. Problems block the upload; warnings are shown and allowed.

    App version and updates

    Update pulls the latest release from GitHub, reinstalls dependencies and restarts the app in place. Your settings and saved packs are kept. This is the same update the desktop launcher runs; do it here when the app is already open.
