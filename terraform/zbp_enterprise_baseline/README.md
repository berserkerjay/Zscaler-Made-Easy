# ZBP Enterprise Policy Pack — Terraform

Generated by DLP-Check from pack `zbp_enterprise_baseline` v1.1 for the official [zscaler/zia](https://registry.terraform.io/providers/zscaler/zia/latest/docs) provider (~> 4.8).

31 dictionaries · 9 engines · 36 rules · **policy pack**

This pack is a policy pack: the reference a tenant is measured against on its data-governance journey. Terraform is convergent by nature, so once objects are in state `terraform plan` shows every way the tenant differs from the reference and `terraform apply` would make them match. Use `plan` to assess; `apply` only when the customer wants the tenant converged (an enabled rule or a hardened action is usually progress to keep, not something to revert — update the pack instead). Objects the policy pack does not define are never touched.

## Use

```bash
terraform init
terraform plan      # review: creates, in-place updates, imports
terraform apply
```

Credentials: `terraform.tfvars` (copy the example) or `ZSCALER_*` environment variables. The client needs a ZIA role with write access to DLP dictionaries, engines and the rule types in this pack.

Ordering: new rules are inserted starting at `rule_starting_order` and push existing rules down. Run `terraform apply -parallelism=1` if the tenant reports ordering conflicts.

`terraform destroy` removes exactly the objects in state, in dependency order.
