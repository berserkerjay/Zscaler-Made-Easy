# ZBP Source Code to AI Baseline — Terraform

Generated by DLP-Check from pack `zbp_source_code_baseline` v1.0 for the official [zscaler/zia](https://registry.terraform.io/providers/zscaler/zia/latest/docs) provider (~> 4.8).

3 dictionaries · 3 engines · 3 rules · **immutable baseline**

This pack is an immutable baseline: with the objects in Terraform state, `terraform plan` reports any drift and `terraform apply` restores it. Objects the baseline does not define are never touched.

## Use

```bash
terraform init
terraform plan      # review: creates, in-place updates, imports
terraform apply
```

Credentials: `terraform.tfvars` (copy the example) or `ZSCALER_*` environment variables. The client needs a ZIA role with write access to DLP dictionaries, engines and the rule types in this pack.

Ordering: new rules are inserted starting at `rule_starting_order` and push existing rules down. Run `terraform apply -parallelism=1` if the tenant reports ordering conflicts.

`terraform destroy` removes exactly the objects in state, in dependency order.
