DLP-Check companion

The address of the DLP-Check app on this computer. A local install listens on http://127.0.0.1:8000; the container on http://127.0.0.1:8001. Only addresses on this computer (127.0.0.1, localhost) are accepted.

The extension stores only this address. It holds no credentials or tenant data: signing in, the UI token, write mode and every tenant read stay in the app.
